## 4. 반드시 알아야 할 제약

### CRLF — 여러 줄 치환이 조용히 실패한다

`core.autocrlf` 때문에 체크아웃된 파일은 `\r\n`, 새로 쓴 파일은 `\n` 이다. `\n` 으로
만든 여러 줄 검색 문자열은 아무것도 못 찾고, 스크립트는 성공한 척 끝난다. **치환 헬퍼는
검색 문자열을 못 찾으면 예외를 던지게 만들고**, 줄바꿈을 정규화한 뒤 원래대로 되돌려
저장한다.

### 브라우저 창이 가려져 있으면 안 움직인다

스크롤 이벤트 · CSS 전환 · `requestAnimationFrame` · smooth scroll 이 전부 돌지
않는다. 캐러셀이나 카운트다운이 멈춘 것처럼 보여도 로직 문제가 아닐 수 있다. DOM을
직접 움직여(`scrollLeft` 대입, `__reactProps*` 에서 `onScroll` 꺼내 호출, 측정값 대신
클래스 이름 읽기) 확인하고, **못 본 부분은 보고서에 그대로 밝힌다.**

### SVG 아이콘은 CSS로 색을 못 바꾼다

`<img>` 안의 SVG라 `currentColor` 가 안 먹는다. 색이 다른 상태가 필요하면 `sed` 로
색만 바꾼 사본을 만들어 갈아 끼운다. 지금 그렇게 만든 짝:

- 어두운 채팅방용 흰색: `community/{back,bell,search,menu}-light.svg`, `chat/sort*-light.svg`
- 하단 탭 켜짐/꺼짐: `home/nav-home-off.svg`, `home/nav-*-on.svg`
- 장바구니 담김: `home/cart-*-on.svg`

**하단 탭 아이콘은 프레임에 홈만 켜진 상태로 그려져 있다.** 그대로 쓰면 어느 화면에서나
홈이 켜져 보인다.

### Figma 내보내기가 배경까지 딸려 온다

`ai.svg` 에는 회색 판과 홈 화면 전체 흰 배경(402×2891) rect 가 같이 들어 있었다.
아이콘 뒤로 흰 네모가 보이면 이걸 의심한다.

### 회전한 요소는 레이아웃 폭이 작다

랜덤 지식깡 카드처럼 기울인 그림은 회전 뒤 차지하는 자리가 원래 크기보다 넓다. Figma가
씌워 둔 바깥 상자를 같이 옮기지 않으면 줄이 좁아지고 잘린다.

### `object-cover` 는 비율이 다르면 잘라낸다

팝콘·지식깡 봉지가 잘린 원인이 전부 이것이었다. 상자와 그림의 비율을 먼저 재고, 다르면
프레임이 지정한 폭·위치를 그대로 쓴다.

### hydration

서버와 브라우저가 다른 값을 그려야 하면 `useSyncExternalStore` 의
`getServerSnapshot` 으로 갈아탄다(무료 지식 타이머가 그 예). 효과 안에서 `setState`
하면 `react-hooks/set-state-in-effect` 에 걸린다.

## 6. 답을 기다리는 질문

1. **모바일 너비** — 지금은 402로 묶여 있어 430px 폰에서 좌우 14px씩 남는다.
   요구사항 3장은 실제 화면 너비에 맞추라고 한다. 풀면 채팅방 로비의 피크닉 장면이
   402 좌표계에 절대배치돼 있어 어긋난다.
2. **Primary 램프의 `#229A70`** — 입력정보 문서에는 있고 토큰에는 없다. 어느 쪽이 최신인지.
3. **게시글 출처 필수 여부** — 지금은 비면 등록이 막힌다. 화면 문구는 "안 적으면 카더라
   표시가 붙어요"라 서로 어긋난다.
4. **게시글 목록의 카테고리 배지** — 아직 파랑 고정이다. 카테고리 색을 따르게 할지.
5. **없는 글·방 처리** — 지금은 조용히 목록으로 되돌린다. 요구사항 7-3은 "삭제됐거나
   존재하지 않는 글"을 구분해 보여주라고 한다.
6. **전체화면에도 알래봇** — 넣으려면 화면마다 바닥 바 높이를 따로 잡아야 한다.
