### 서비스

- **서비스명**: 알래말래븐 — "24시간 지식 편의점"
- **커뮤니티 주제**: 일상 잡지식(생활상식 · 과학 · 역사 · 사회 · 문화)의 수집과 검증, 그리고 토론
- **주요 사용자**: 쇼츠 · SNS로 잡지식을 자주 접하지만, 기억에 남기지 못하거나 출처를 확인하지 못해 답답한 20~30대
- **서비스의 핵심 목적**:
  잡지식은 재밌게 소비되지만 두 가지 한계가 있다. (1) 금방 잊히고, (2) 출처가 불명확해 신뢰하기 어렵다.
  편의점에서 상품을 고르듯 지식을 담고, 하루치를 **영수증**으로 발행해 기록으로 남기며, 모든 콘텐츠와 AI 답변에 **출처**를 붙여
  "잊히지 않고 믿을 수 있는 지식 경험"으로 바꾼다.
- **핵심 기능**:
  - **홈** — 공지 배너(HOT/NEW) · 관심 주제 태그 · 오늘의 맞춤 상품 · 잡 지식 세트(주 1회 미션 + 퀴즈) · 점장님 Pick · 24시간 한정 지식(자정 폐기, 무료) · 랜덤 지식깡 · 남긴 상품(이어보기)
  - **카테고리** — 5개 대분류(사회 / 역사 / 과학 / 문화 / 생활) → 카테고리 상세 → 지식 상세
  - **기록** — 영수증(매일 자정 자동 발행) · 영수증 꾸미기(테마 · 스티커 · 폰트) · 월간지식(캘린더) · 주간지식(바 스택)
  - **커뮤니티** — 게시글(출처 필수, 미입력 시 "카더라" 표시) · 채팅방 · 토론방(A vs B 투표 · 근거 달기) · 나의 활동
  - **지식 장바구니** — 담아둠 / 먹는 중 / 다 먹음 3단계 상태 · 바구니형 · 목록형 보기 · 다중 선택 후 영수증에 담기
  - **MY** — 출석(7일 연속 +10코인) · 관심 카테고리 · 통계 · 구독(체크 / 신용 / 블랙) · 가챠(블랙 전용) · 코인샵
  - **코인** — 획득: 출석 +10 / 세트 퀴즈 +3 / 토론 승리 +1 / 구독 월 지급 · 사용: 지식 열람 −1(24시간 한정 지식은 무료) / 랜덤 지식깡 −1 / 영수증 유료 테마 · 스티커
  - **공통** — 검색(인기 랭킹 1~5) · 알림 · 지식 상세(출처 링크 · 관련 지식 · AI에게 물어보기)
- **AI 챗봇의 보조 역할**: **사용 안내 + 정보 탐색 + 출처 확인 보조**
  챗봇 이름은 "알래봇". 지식 상세의 「AI에게 물어보기」와 커뮤니티 탭에서 진입한다.
  빠른 버튼 6개 — 오늘의 지식 추천 / 이 글 요약해줘 / 퀴즈 만들어줘 / 출처 찾아줘 / 내 영수증 정리 / 기타 질문.
  커뮤니티가 서비스의 중심이므로, 챗봇은 전면 서비스가 아니라 탐색 · 요약 · 출처 확인을 돕는 보조 도구로 유지한다.
